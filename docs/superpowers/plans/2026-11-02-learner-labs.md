# Learner Lab Walkthroughs Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Bring the structure guide and all ten lab walkthroughs into agreement and make each self-contained, stepwise, and usable by first-time learners.

**Architecture:** Treat the structure guide as the normative contract. Audit all ten labs and their setup dependencies, revise only learner instructions and Evidence checklists, and base expected outputs on fresh runs captured by the artifact/runtime and release-QA plans.

**Tech Stack:** MkDocs Material Markdown, existing Python `unittest` structural tests, local Android/Devom/BugBazaar lab setups.

**Spec:** `docs/superpowers/specs/2026-11-02-production-ready-lab-site-design.md`

## Global Constraints

- Use disposable, isolated environments only; no public or corporate exposure.
- Restrict egress to required paths and use synthetic data only.
- Preserve existing redaction rules for tokens, keys, service-account material, personal data, and unrelated device content.
- Keep existing structural checks; add no tests that assert prose, spelling, or wording quality.
- Every walkthrough step states where to work, what to do, and what to check.
- Explain terms and placeholders when first introduced.
- Every Evidence section is a fill-in checklist mapped to a producing step or command and completable with the documented setup alone.
- All lab run outputs and screenshots must be freshly observed; never invent results.
- Use repo-hosted APKs and their documented SHA-256 verification; no external APK download sites.
- Implementation must happen in a new branch/worktree based on the branch containing the approved spec.

## Review Focus

- Evidence item has no producer or requires unstated credentials/tooling: map every item to a step and setup-listed tool, or remove it.
- Placeholder is ambiguous or first appears without a definition: define its value/format before first command use.
- Expected result is not confirmed by a fresh run: label source-derived facts accurately and avoid runtime claims until observed.
- Lab 27 setup drifts from local emulator-only operation: use the exact configuration produced by the artifact plan.
- Safety scope is lost in a lab-specific command: review each command and network path against the global constraints.
